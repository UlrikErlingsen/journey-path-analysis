# Working-name screen: Trace Signal

Screen date: 17 July 2026.

> **Display name since 1.1.0:** the product is written **Trace Signal** (with a space) in the Signal brand refresh; the package, file and environment-variable names stay `tracesignal` / `TRACESIGNAL_*`. The screen below was run on the exact combined string “TraceSignal” and has not been repeated for the spaced form. The refresh changes spelling only and claims no new clearance.

## Result

**TraceSignal is a plausible working name, but it is not legally cleared.** An exact-string web screen found no active company or product named "TraceSignal." The nearest uses found are different in word order, category, or kind:

- `slreportgen.utils.traceSignal`, a MATLAB Report Generator API function for tracing signal lines in Simulink models — a vendor API utility, not a competing product name;
- an IBM z/VM trace event named "trace signal" in mainframe system documentation — generic system terminology;
- "signal trace," the generic electronics term for a conductive track on a printed circuit board;
- REVERSED-order products named **SignalTrace**: a honeypot/tracking platform at trysignaltrace.com, an ELSAG/Leonardo law-enforcement signal-intelligence system, and signaltrace.ai prospect intelligence — different word order and different categories from journey event-log analytics.

The exact PyPI and GitHub name slots were open at screen time.

## Practical assessment

- **Direct exact-name conflict found:** none in the basic web screen.
- **Conceptual fit:** strong for a tool that traces observed journey sequences through an event log.
- **Discoverability:** moderate; "trace" and "signal" are both common technical words, and the reversed-order "SignalTrace" products create some search friction.
- **Legal confidence:** low, because no formal trademark clearance was performed.

## Limits

This was a practical product-name screen, not legal advice or a trademark opinion or clearance. It did not exhaust official trademark registers, national company registers, common-law rights, domains and historical ownership, app stores, social handles, translations, or every relevant class and jurisdiction. Search absence is not proof of availability.

## Recommendation

Retain **Trace Signal** (screened as “TraceSignal”) as the working title. Before commercial use or any release where the name carries material value, check exact and similar spellings (including the reversed-order "SignalTrace" marks) in the relevant official trademark and company registers, confirm domain and social-handle strategy, repeat GitHub/PyPI/npm/app-store searches, and obtain qualified legal advice.
